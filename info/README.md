# Info

This directory contains information about various generations
of compute nodes.  They are organized by CPU architecture.

The folluwing information is provided for each generation of compute node:

- cpuinfo (`/proc/cpuinfo` output)
- meminfo (`/proc/meminfo` output)
- memspec (`dmidecode --type memory` output for memory devices)
- mlc (mlc output for memory latency and bandwidth)
